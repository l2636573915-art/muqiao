# 培训展示页更新说明

这个网站已经改成 **Excel 驱动**。网页不再写死培训内容，而是自动读取：

`data/培训材料.xlsx`

## 以后新增培训怎么做

1. 打开 `data/培训材料.xlsx`。
2. 在 `Sheet1` 最后一行新增培训。
3. 至少填写：`适合人群`、`培训内容`、`培训材料及回放`；为了页面更好看，建议同时填写 `展示名称`、`展示分类`、`录屏状态`。
4. `是否展示` 填“是”；不想给客户看的旧培训改成“否”即可，不用删除。
5. `排序` 填数字，数字越小越靠前，建议用 10、20、30……，以后容易插入新课程。
6. 保存文件，文件名保持 **培训材料.xlsx** 不变。
7. 上传并覆盖网站 `data/培训材料.xlsx`，刷新网站即可自动更新。

## 推荐字段

- 培训主题：原始培训类型/主题
- 适合人群：客户在卡片上会看到
- 培训内容：一行一个学习点即可
- 培训材料及回放：可以在一个单元格中放多个“标题 + URL”
- 录屏状态：只填“有录屏”或“无录屏”
- 展示名称：客户看到的课程名称
- 展示分类：用于页面筛选
- 培训等级：用于课程卡片标签
- 标签：多个标签用中文分号 `；` 隔开
- 是否展示：是 / 否
- 排序：数字越小越靠前

## 本地预览

如果直接双击 `index.html`，浏览器通常不允许网页自动读取同目录的 Excel。此时页面会自动出现“选择培训材料.xlsx 本地预览”的按钮。

部署到 GitHub Pages 等 Web 环境后，网页会自动读取 `data/培训材料.xlsx`，客户不需要手动选择文件。

## 网站目录不要改

```text
├── index.html
├── style.css
├── app.js
├── README_更新说明.md
└── data/
    └── 培训材料.xlsx
```

日常只需要更新 `data/培训材料.xlsx`。
