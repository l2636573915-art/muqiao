来源：https://www.yingdao.com/yddoc/rpa/zh-CN

范围：官方帮助中心「指令文档」栏目（不含「接口文档」「快速入门」等其他栏目，不含未公开企业指令）。

## 数据清单

- 指令文档节点：2680；目录文件夹节点：319；一级分类：20。
- 对应文档内容读取：2680 / 2680 成功。
- 功能描述抽取：2662 / 2680；输入参数识别：1846 / 2680；输出参数识别：1285 / 2680。
- 指令ID唯一：2680 / 2680。
- 标题有同名现象，不能用标题当主键；请使用文档 ID。
- “正文读取成功”不等于“所有参数字段都成功抽取”，老旧文档的章节格式并不统一。

## 下载和使用

请下载 `yingdao-catalog-full-csv.zip`，解压后获得：
1. `yingdao_docs_full.csv`：逐条目录（原始分类路径、平台、名称、原文链接、状态、功能描述、输入参数名、输出参数名、案例摘要、标题等）。
2. `yingdao_folders.csv`：完整分类目录结构。
3. `yingdao_summary.json`：分类数量、正文采集汇总。

CSV 使用 UTF-8 with BOM 编码，Excel 可直接打开。

## 采集方法

依据官方前端公开目录接口：
`https://api.yingdao.com/api/noauth/v1/yddoc/menus/getMenuTreeByBrandCode?brandCode=rpa&languageCode=zh-CN`

并逐项获取官方公开正文（目录内 doc ID 与正文一一关联）。采集未涉及用户登录或非公开内容；每条数据保留原文链接。因官网持续更新，属于采集时点快照。

注意：本项目第一阶段仅整理指令文档。暂不据此推定业务地图的实际完整性或企业业务流程。
