采集日期：2026-10-22。来源：<https://www.yingdao.com/yddoc/rpa/zh-CN>

## 数据范围与结论

- 官方栏目「指令文档」：**2680** 个文档叶子节点、**319** 个文件夹节点、**20** 个一级分类。
- 本轮已完整读取并保存 **2680/2680** 篇公开文档的 Tiptap JSON 结构；总 ID 数 **2680，全部唯一**。
- **2273** 篇归于「自定义指令」，其下归类到 **231** 个具有指令文档的平台/系统子目录（这是目录数，不是去重后的平台品牌数）。
- 之前自动提取的描述覆盖 2662 篇，输入参数标签覆盖 1846 篇，输出参数标签覆盖 1285 篇；**参数抽取覆盖率≠正文获取覆盖率**，原文均保存，可以重新解析。
- 同名指令文档可能来自不同系统或版本，主键为官方 **ID**，不按标题删除。
- 公开网站数据快照，不含未公开/企业登录后可见指令；图片仅保留正文结构中的引用地址，**未打包下载图片二进制**。

## 交付文件

**目录与检索**：`yingdao-index-platforms-v1.1.zip`（解压后可见）
- `全部指令_2680条.csv`：每条指令一行，原始分类、平台/系统子目录、输入/输出、功能摘要、官方原文链接和采集状态。
- `平台系统汇总.csv`：231 个平台/系统子目录及指令数量。
- `一级分类汇总.csv`：20 个官方一级分类数量。
- `影刀指令全量检索.html`：无需服务器，下载后用浏览器打开，可搜索/过滤 2680 条指令。
- `采集对账报告.json`。

**完整正文**：8 个独立的 `yingdao-fulltext-part-*.jsonl.xz` 分卷，每卷包含 335 条原文，总计 2680 条。
- 用 7-Zip 或 Python `lzma` 解压 `.xz`。
- 每行是一个 JSON 对象，字段含 `id, title, path, source_url, status, plaintext, source_structure`。
- `source_structure` 是官方富文本原始节点，可用于后续提取参数、图片链接、示例、表格和业务语义。
- 这 8 个分卷是**相互独立的归档**，不是需要二进制拼接的分卷压缩包；逐个解压后合并 JSONL 内容即可。

## 验收与注意事项

已核对所有 8 卷解压后每条 JSON 可被解析，各卷 335 条，合计 2680 条，无重复主键。该版本**不展开业务地图/本体推断**，严格先保留来源事实。后续按平台归并时需要对“亚马逊卖家后台、亚马逊VC、亚马逊广告”等官方多个目录额外进行标准化映射，不可直接将原始文件夹数误认为平台数。

对于图片、视频等附件，原始结构内保留指针；如需建立完全离线的多媒体镜像，应另行采集附件并遵守相关使用限制。
