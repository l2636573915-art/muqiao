# 影刀全平台指令能力底库 V1.2 — 2026-10-22

第一阶段 2,680 篇文档的全量采集已完成。本版本是第二步：**归并平台/系统名称，建立技术动作分类，保留与原始指令文档的追溯关系。** 尚未开展业务地图与本体建模。

## 统计

- 官方指令文档叶子页面：2680（唯一 ID 2680）。
- 其中官方「自定义指令」目录：2273 篇，归属 231 个包含文档的官方平台/系统子目录；其他原生分类 407 篇。
- 规则归并成 79 个标准检索单元（**包括**通用工具桶和待确认桶，非 79 个独立品牌），48 个生态标签。
- 仅凭目录名称无法可靠匹配平台的：4 个官方子目录、7 篇文档。保留为「待确认的系统或扩展」。
- 文档标题匹配不到可靠操作动词的：877 篇，保留「其他/待复核」，不自动杜撰功能。
- 名称疑似为更新说明、参数指南等非可执行指令文档：36 篇（关键词提示，需要核查，不能当最终剔除数量）。
- Excel/WPS 等工具类、Adobe 创意工具、验证码工具、办公系统和电商/ERP 平台均纳入，未将全部「自定义指令」误称为“电商平台”。

## 下载

`影刀_全平台指令能力底库_V1.2.zip` 包含：
- `指令主库_2680条_标准化.csv`：原名、ID、官方分类及目录、标准平台、生态、技术动作、操作对象、输入输出摘要、官方链接。
- `平台归并对照_231目录.csv`：目录级映射及需要审核标记。
- `平台汇总_标准平台.csv`：标准平台聚合信息和包含的原始目录。
- `平台能力矩阵.csv`：标准平台 × 指令操作类型的交叉统计。
- `待人工确认_目录.csv`：目录无法判断所属平台的明细。
- `疑似说明类文档_待核验.csv`：可能属于说明而非独立可执行能力的文档候选。
- `分析质量报告.json`：分布和可追溯性核验。
- `全平台指令能力地图_V1.2.html`：可以**直接在本地浏览器打开**的检索与筛选原型，无需服务器。
- `README.md`。

以上 CSV 统一使用 UTF-8 BOM，可用 Excel 打开。完整正文另见相邻 `v1.1` 文件夹下 8 卷的 JSONL 原文归档。

## 规范边界

1. 2,680 = 官方「指令文档」叶子页面数，不等于去重后真实可执行指令数。
2. 平台归并是研究性规则，不是影刀官方分类；原始目录和原始 URL 永久保留。
3. 技术动作分类主要基于标题字面，不代表已阅读全部流程、参数机制或完成实测。
4. 目前不从指令名称直接推断企业业务域、业务价值或可落地 SOP；这些进入后续阶段，并需要外部业务知识校验。
