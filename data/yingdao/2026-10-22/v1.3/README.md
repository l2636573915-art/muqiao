# 影刀指令正文证据分类 V1.3

采集基础：2026-10-22 官方帮助中心「指令文档」2,680 篇目录与原文（详见 v1.1）。

## 本次交付

对 V1.2 里动作类型为「其他/待复核」的 877 篇重点检查了官方标题与原文中的「描述」段，并采用审慎的规则辅助分类。

- **709 篇**可提出候选动作类型；
- **164 篇**仍缺乏足够依据，保留待人工判定；
- **4 篇**识别为说明类候选（以上合计 877）。
- 全库 36 篇页面标注为说明类候选，不能直接等于已确认非指令文档。
- 发现 10 组、24 篇不同文档复用完全相同的「描述」段，标记 P0 优先审核；重复文本并不必然表明错误。
- 其余原本已分类的 **1,803 篇**主要沿用 V1.2 判断，未逐项复查、未实测。
- 包内 HTML 支持筛选、跳转官方文档、导出筛选结果 CSV；ZIP 全部文件均是 UTF-8 / UTF-8 BOM。

## 准确性边界

这是**可追溯的机器候选分类**，不是人工逐条审核结论，不能直接把「候选动作」当成客户业务所需能力或生产环境支持证明。原始网页与富文本 JSONL 在同仓库的 v1.1 文件夹中；平台标准化映射在 v1.2 文件夹中。
